# UCI Household Power Consumption Time Series Forecasting

---

## 要約

目的 : 過去の家庭用電力使用量データから、日次平均の `Global_active_power` を予測する  
手法 : ベースライン予測、指数平滑化系モデル、通常特徴量を用いた機械学習モデルを比較する  
評価方法 : MAE、RMSE、MAPE、MASE、残差分析  
結果 : 通常特徴量を用いた `GradientBoosting` が最良の結果を示した  
使用技術 : Python / pandas / matplotlib / seaborn / scikit-learn / statsmodels / sktime  

---

この分析では、UCI Individual Household Electric Power Consumption データを用いて、家庭全体の有効電力消費量である `Global_active_power` の日次平均を予測しました。

本 notebook は、通常の時系列解析として以下を実施しています。

1. データの確認

3. 日次平均系列の作成
4. 可視化による傾向把握
5. トレンド・季節性の分解
6. 時系列順の train / test 分割
7. ベースラインモデルの作成
8. 指数平滑化モデルと機械学習モデルの作成
9. 評価指標による比較
10. 残差分析
11. モデル比較
12. 結果の解釈

最終的には、通常特徴量のみを用いたモデルの代表として `GradientBoosting` を採用し、今後の TDA 特徴量追加モデルとの比較対象にする方針としました。

## 分析のポイント

### 1. データ確認・前処理

元データは `Date` と `Time` が分かれているため、両者を結合して `datetime` 型の時系列インデックスを作成しました。

また、数値列は `float` に変換し、欠損値、重複時刻、時系列の間隔を確認しました。その後、予測対象として `Global_active_power` の日次平均系列を作成しました。

#### 処理内容

- `Date` と `Time` を結合して `datetime` を作成
- 数値列を `float` 型に変換
- 欠損値の確認と処理
- 重複時刻の確認
- 1分間隔の時系列として整形
- `Global_active_power` を日次平均に集約

---

### 2. 可視化による傾向把握

可視化では、以下の観点から `Global_active_power` の特徴を確認しました。

- 日次平均の推移
- 最初の1週間の分単位推移
- 移動平均
- 時刻ごとの平均使用量
- 曜日ごとの平均使用量
- 月ごとの平均使用量
- 日次平均・日次最大・日次最小の比較

#### 確認できた傾向

- 明確な一方向の長期トレンドは確認しにくい
- 日内周期、曜日効果、月ごとの季節性が見られる
- 分単位データでは短時間のスパイクが多い
- 深夜から早朝は使用量が低く、朝・夕方から夜に高くなる傾向がある
- 冬に高く、夏に低い季節パターンが見られる

この結果から、以降の予測では日次平均系列を対象とし、曜日・月・ラグ特徴量・移動平均特徴量を用いる方針としました。

---

### 3. トレンド・季節性の分解

`Global_active_power` の日次平均系列に対して、加法型の季節分解を行いました。

#### 確認内容

- トレンド成分
- 季節成分
- 残差成分
- 季節調整済み系列
- トレンド除去済み系列
- トレンド・季節性を両方除去した系列

#### 解釈

季節調整済み系列は、原系列と大きく異なる形にはなりませんでした。

ただし、時刻・曜日・月ごとの平均使用量には一定のパターンが見られるため、季節性が存在しないとは断定せず、原系列全体の変動に比べると季節調整による変化が小さいと解釈しました。

---

### 4. 特徴量作成

通常特徴量モデルでは、日次平均系列から以下の特徴量を作成しました。

| 特徴量 | 内容 |
|---|---|
| `lag_1` | 1日前の値 |
| `lag_2` | 2日前の値 |
| `lag_3` | 3日前の値 |
| `lag_7` | 7日前の値 |
| `lag_14` | 14日前の値 |
| `rolling_mean_7` | 過去7日の移動平均 |
| `rolling_mean_14` | 過去14日の移動平均 |
| `rolling_std_7` | 過去7日の移動標準偏差 |
| `rolling_std_14` | 過去14日の移動標準偏差 |
| `dayofweek` | 曜日 |
| `month` | 月 |
| `is_weekend` | 週末フラグ |

これらの特徴量により、直近の使用量水準、短期的な変動、曜日効果、月ごとの季節性をモデルに反映しました。

## 残差分析

最良モデルである `GradientBoosting` について、残差分析を行いました。

### 確認内容

- 実測値と予測値の比較
- 残差の時系列プロット
- 残差の分布
- 残差の基本統計量
- 残差の自己相関
- 曜日別の残差
- 月別の残差
- 予測値と残差の関係

### 解釈

`GradientBoosting` の残差は概ね0を中心に推移しており、平均的な過大予測・過小予測の偏りは大きくありませんでした。

また、曜日別・月別に見ても、特定の曜日や月だけ残差が大きく偏る傾向は目立ちませんでした。

一方で、一部の時点では比較的大きな残差が確認されました。これは、通常のラグ特徴量や曜日・月の特徴量だけでは説明しにくい突発的な使用量変化やスパイクが含まれている可能性を示しています。

## 結論

本分析では、UCI Individual Household Electric Power Consumption データを用いて、日次平均の `Global_active_power` を予測しました。

評価の結果、通常特徴量を用いた `GradientBoosting` が、MAE、RMSE、MAPE、MASE のすべてで最良の結果を示しました。

特に、以下の点から `GradientBoosting` を採用モデルとしました。

- すべての評価指標で最小値を示した
- ナイーブ予測よりも明確に改善した
- 季節ナイーブ予測よりも改善した
- MASE が 1 未満であった
- 残差の平均的な偏りが大きくなかった

ただし、今回の結果は、使用した特徴量、評価期間、評価指標において `GradientBoosting` が最も良かったという意味です。  
常に `GradientBoosting` が最良であると断定するものではありません。

また、本分析では test 期間中も前日までの実測値が利用できる前提で特徴量を作成しています。  
そのため、このモデルは長期を一括で予測するモデルというより、前日までの情報を用いて翌日を予測する逐次的な短期予測モデルとして解釈するのが適切です。
